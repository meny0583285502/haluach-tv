# הלוח TV

אפליקציה לטלוויזיית אנדרואיד שמציגה את https://haluach.pages.dev/ במסך מלא כל הזמן.
יוצאים ממנה רק עם סיסמת מנהל.

- **חלון הסיסמה:** לוחצים 5 פעמים מהר על "חזור" בשלט, או על כפתור התפריט.
- **ה-APK נבנה אוטומטית** ב-GitHub Actions בכל שינוי, ומתפרסם בדף Releases.
- **קישור קבוע להורדה:** `https://github.com/meny0583285502/haluach-tv/releases/latest/download/haluach-tv.apk`
