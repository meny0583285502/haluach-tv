# הלוח TV

אפליקציה לטלוויזיית אנדרואיד שמציגה את https://haluach.pages.dev/ במסך מלא כל הזמן.
יוצאים ממנה רק עם סיסמת מנהל.

- **חלון הסיסמה:** לוחצים 5 פעמים מהר על "חזור" בשלט, או על כפתור התפריט.
- **ה-APK נבנה אוטומטית** ב-GitHub Actions בכל שינוי, ומתפרסם בדף Releases.
- **קישור קבוע להורדה:** `https://github.com/meny0583285502/haluach-tv/releases/latest/download/haluach-tv.apk`

## יציאה מהאתר עצמו
האתר יכול לשחרר את הנעילה אחרי שהוקלדה בו סיסמה נכונה:
```js
if (window.HaluachTV) HaluachTV.exit();          // יציאה עד שהטלוויזיה תכבה ותידלק
if (window.HaluachTV) HaluachTV.exitMinutes(30); // יציאה ל-30 דקות
if (window.HaluachTV) HaluachTV.menu();          // פתיחת תפריט המנהל
```

## בלי אינטרנט
האפליקציה שומרת את האתר. כשאין אינטרנט היא מציגה את מה שנשמר בפעם האחרונה, וכשהאינטרנט חוזר היא טוענת לבד את הגרסה העדכנית.
